# AGline plugin for Claude Code

Gives Claude Code a phone line to you: it can call you for a decision, text you updates, and read your replies.

```
/plugin marketplace add imjarvissingh/agline-plugin
/plugin install agline@agline
```

Get your private number at https://agline.in. The plugin connects Claude Code to the AGline MCP server at `https://agline.in/mcp` and adds a skill that teaches Claude when to call you and when to text.

Support: agofficial@agline.in
